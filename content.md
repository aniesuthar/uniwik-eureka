Uniwik Landing Page — Development Brief

Objective

Redesign the current Uniwik website (uniwik.com) around the new Uniwik product direction.

The previous positioning around “Verified Brand Profiles” is no longer the core product and should be removed from the homepage.

Uniwik is currently being rebuilt as a consumer discovery and organization platform.

The product is not a marketplace and does not sell products directly.

⸻

Core Product Positioning

One-line description

Uniwik helps you save, organize and revisit the things you discover across the internet.

People discover products, brands, ideas and useful content across Instagram, YouTube, Amazon, Flipkart, brand websites, WhatsApp, etc. Today these discoveries are scattered across screenshots, saved posts, messages, browser bookmarks and random notes.

Uniwik gives users one organized place for these discoveries.

Core flow

Discover → Save → Organize → Revisit

Examples:

* Discover a product on Instagram → save it to Uniwik
* Find a product on Amazon → save it
* Find a brand website → save it
* See something useful on YouTube → save it
* Organize saved items into personal collections
* Return later when ready to compare, buy or explore

Important Positioning Rules

Do NOT call Uniwik:

* A marketplace
* An e-commerce website
* A shopping website
* A social network
* A brand directory
* A brand verification platform

Do NOT currently promote:

* Verified Brand Profiles
* Brand verification
* Brand policy monitoring
* Fake website detection
* Unified login
* Order syncing
* RTO/Karma
* Number masking
* Other future features

Those can be part of the long-term roadmap but are not the current product.

⸻

Design Direction

The website should feel like a modern consumer technology startup, not a traditional SaaS/business website.

Prioritize:

* Clean layout
* Strong typography
* Lots of whitespace
* Product UI visuals
* Short sections
* Clear hierarchy
* Mobile-first responsiveness
* Fast loading
* Strong CTA

Avoid:

* Excessive gradients
* Generic AI/startup illustrations
* Stock photos
* Fake statistics
* Fake user testimonials
* Claims about users/revenue/traction that we don’t have
* “Revolutionary”, “game-changing”, “next-generation” type hype

The product should feel real, useful and early, rather than pretending to already be a huge company.

⸻

Important Technical Requirement

The existing website may contain content from the previous Uniwik concept.

Audit the entire homepage and remove/replace outdated positioning.

Do not simply add a new section above the existing content.

The homepage should communicate one consistent product:

Uniwik = a place to save, organize and revisit things discovered across the internet.

The website must also clearly state that Uniwik is currently in development / early access if the product is not publicly launched yet.

⸻

Eureka Alignment

The website should be consistent with the description we will submit to Eureka! IIT Bombay.

The Eureka evaluator should be able to:

1. Read the application.
2. Visit uniwik.com.
3. Immediately understand the same problem and solution.
4. See what the product is being built to do.
5. Understand that it is an early-stage product rather than an already mature platform.

Do not optimize the website specifically to “look impressive” for Eureka.

Build it as the real Uniwik landing page.
